# Place Your Social Preview Image Here

## Quick Start

1. **Save your image** as `og-image.jpg` in this directory (public/)
2. **Recommended specs**: 1200 x 630 pixels
3. **Your image**: Use the Japanese-style artwork with the person and laptop

## File Location
```
public/og-image.jpg  ← Your image goes here!
```

## What This Image Does

When someone shares a link from your Cool URLs app:
- On WhatsApp: Shows a preview card with your image
- On Twitter: Displays a large image card
- On Facebook: Shows a rich link preview
- On LinkedIn: Displays professional link preview

## Image Requirements

- **Dimensions**: 1200 x 630 pixels (1.91:1 aspect ratio)
- **Format**: JPG or PNG (JPG recommended for smaller file size)
- **File size**: Under 8MB
- **File name**: Must be exactly `og-image.jpg`

## Resize Your Image (if needed)

If your image isn't 1200x630, you can resize it online:
- Use: https://www.iloveimg.com/resize-image
- Or: https://www.canva.com/ (search for "Open Graph Image" template)

Just export as JPG and save as `og-image.jpg` in this folder!

## Testing

After adding your image:
1. Restart your dev server: `npm run dev`
2. Test at: https://metatags.io/
3. Or share a link on WhatsApp to see it live!
